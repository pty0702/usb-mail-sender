# 客户邮件定时发送器 · 使用说明

双击「**邮件定时发送器.exe**」打开图形窗口。所有东西都在这个文件夹里：换电脑把整个文件夹拷走即可，无需安装、无需重新配置。

---

## 一、文件夹里有什么

| 文件 | 作用 |
|---|---|
| 邮件定时发送器.exe | 图形界面（日常只用这一个） |
| mailgrid.exe | 发送引擎（界面在后台调用，不用直接操作） |
| smtp.json | 发件邮箱配置（已填好，一般不用动） |
| 任务表.xlsx | **发送计划表：几点、给谁、发什么内容，全在这里填** |
| base_template.html | 邮件版式模板（"Hi 名字," 开头 + 正文 + 名片签名） |
| poster.jpg / logo.png / badge.gif | 邮件里的图：宣传海报（任务表配图列引用）、签名 logo、资质徽章 |
| 使用说明.md | 本文件 |

## 二、第一次使用（三步）

**第 1 步：确认发件邮箱配置**
smtp.json 已预填发件邮箱和客户端专用密码。如果发信时提示"认证失败"，按顺序检查：
1. smtp.json 里 `username` / `from` 是否是正确的发件邮箱地址；
2. 该邮箱网页版 → 设置 → 客户端设置里，**IMAP/SMTP 服务**是否已开启；
3. 授权码是否是最近生成且未被删除的（网页版可随时重新生成一个，填进 `password`）；
4. 换个网络再试（提示 "system busy" 时多半是网络风控，稍等或换网络）。

**第 2 步：填写任务表**
打开软件，点「**生成任务表范本**」→ 用 Excel/WPS 打开范本 → 按每列的灰色提示填写：
- **时间**：几点发（如 08:00）。同一时间的多行客户到点一起发，每天到点重复发；
- **客户名字**：程序自动拼成邮件开头的「Hi 名字，」（Hi、空格、英文逗号都不用写）；
- **客户邮箱**：收件人（必填）；
- **抄送邮箱**：可留空；多人用英文逗号隔开；
- **正文内容**：从"Hi 名字，"之后写起，可多段，每行客户可以完全不同；
- **配图**：图片文件名（如 poster.jpg），可留空；图片文件放本文件夹。
保存为 **.xlsx** 格式。范本里附了完整的「填写说明」工作表和示例行。

**第 3 步：启动**
回到软件点「**▶ 启动每日定时**」，窗口保持开着（可最小化）。到点自动发送；修改任务表保存后一分钟内自动生效，不用重启软件。

## 三、日常使用

- **改时间/改客户/改内容**：直接改任务表保存即可；
- **立即测试**：点「立即测试发送」，输入任务表里的某个时间（如 08:00），马上发那一批；
- **换电脑**：整个文件夹拷走，双击 exe 继续；
- **发件记录**：发送结果实时显示在窗口日志里，失败的客户记录在 failed.csv。

## 四、常见问题

- **提示 535 认证失败**：见上文"第一次使用"第 1 步的四个检查点。
- **客户收到进垃圾箱**：新邮箱前几周每天 20~50 封起步，逐步增加；名单真实、勿买名单。
- **想换邮件版式/签名**：记事本打开 base_template.html，正文结构和【签名开始】到【签名结束】之间的文字可改，其他别动。
- **想换配图**：用新图片覆盖 poster.jpg（任务表配图列写的哪个文件名就用哪张）。
