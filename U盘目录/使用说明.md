# 客户邮件定时发送工具 · 使用说明

一个完全本地运行的邮件定时群发工具。所有配置、客户名单、模板、签名、发送记录都在**同一个文件夹**里——这个文件夹放在 U 盘、D 盘、桌面都可以；换电脑时把整个文件夹拷走，双击「1-启动每日定时发送」即可继续使用，无需重新配置、无需安装任何软件。

> 本工具以 zip 压缩包通过微信发送。若微信提示"该文件可能包含可执行程序，请注意甄别"，属正常提醒，点「仍要保存」即可；解压后先双击「3-预览邮件效果」确认正常再使用。

---

## 一、文件说明

| 文件 | 作用 |
|---|---|
| mailgrid.exe | 发送程序本体（免安装） |
| config.json | 腾讯企业邮箱 SMTP 配置（只需填一次） |
| recipients.csv | 客户名单（Excel 可编辑，四列） |
| template.html | 邮件模板（含邮件正文和签名） |
| poster.jpg / logo.png / badge.gif | 邮件里的三张图：宣传海报、签名 logo、资质徽章（替换图片时保持文件名不变即可） |
| 签名.txt | 可选：想在所有邮件末尾额外附一句话时才用，默认留空 |
| 1-启动每日定时发送.bat | 每天 09:00 自动发送（保持窗口开着） |
| 2-立即发送测试.bat | 不等定时，立即给 group=A 的客户发一封 |
| 3-预览邮件效果.bat | 只渲染预览、不实际发送，用来检查模板 |
| sent.csv / failed.csv | 发送成功 / 失败记录（程序自动生成） |

## 二、首次配置（只需一次）

1. **开通信箱 SMTP**：登录腾讯企业邮箱网页版 → 设置 → 客户端设置，开启「IMAP/SMTP 服务」，生成**客户端专用密码**（不是邮箱登录密码）。
2. **编辑 config.json**（记事本打开），改这三处：
   ```json
   "username": "你的发件邮箱@公司域名.com",
   "password": "刚才生成的客户端专用密码",
   "from": "你的发件邮箱@公司域名.com"
   ```
   服务器和端口已按官方参数填好：smtp.exmail.qq.com，SSL 端口 465。
3. **编辑客户名单**：双击 recipients.csv（Excel 打开），**第一列表头行不要动**，四列含义：
   - `name`：客户名字（自动替换进邮件开头的 "Hi 客户名字,"）
   - `email`：客户邮箱
   - `cc`：这封邮件抄送给谁（可以每行不同，也可以留空不抄送；多人用英文逗号分隔）
   - `group`：分组标记（A/B/C…，用于按组轮换发送）

   另外所有邮件都会固定抄送给 sue.s@pak-eco.com 和 1430404507@qq.com（写在 bat 脚本里，如需修改告诉我方改）。

## 三、邮件内容在哪改

- **邮件正文、海报图、签名**：都在 template.html 里。用记事本打开，正文部分和【签名开始】到【签名结束】之间的文字（姓名、部门、电话、网址等）可以直接改，其他符号别动。
- **三张图**：直接用新图片覆盖 poster.jpg、logo.png、badge.gif（保持文件名不变）。
- **邮件主题**：现在是 "TEST 2026"，改 bat 脚本里 `--subject "TEST 2026"` 的引号内文字。
- **额外附言**：写进签名.txt（默认留空 = 不加）。

## 四、每天怎么发

1. 早上开机后，双击「**1-启动每日定时发送**」，窗口保持开着（可最小化）。
2. 每天 **09:00** 自动把名单里的客户全部发出（每封自动带上该客户的称呼、配图和签名）。
3. 下班关机直接关窗口即可；第二天开机重新双击即可，计划不变。

> 注意：定时只在程序窗口开着的时候生效。如果电脑 09:00 没开机，当天就不会自动发（可以开机后用「2-立即发送测试」补发）。

## 五、按组轮换发送

名单里的 `group` 列用来分组轮换。例如周一、三、五发 A 组，周二、四发 B 组：

- 修改「1-启动每日定时发送.bat」，把 `--cron "0 9 * * *"` 改成：
  - A 组：`--cron "0 9 * * 1,3,5"` 并加上 `--filter "group == \"A\""`
  - B 组：`--cron "0 9 * * 2,4,6"` 并加上 `--filter "group == \"B\""`
- 一个窗口只能跑一个定时任务；要两组同时定时，就把 bat 复制一份、改参数、两个窗口都开着。

## 六、换电脑迁移

1. 把整个文件夹拷到新电脑（U 盘拷、微信传压缩包都行）。
2. 双击「1-启动每日定时发送」——配置、名单、模板、历史记录全部原样可用。
3. 新电脑无需安装任何软件（Windows 10/11 64 位直接运行）。

## 七、常见问题

- **发送失败**：先看 failed.csv 里的失败原因；多数是授权码错误（重新生成）或网络不通。
- **客户收到邮件进垃圾箱**：新邮箱前几周发量小一点（每天 20~50 封），逐步增加；名单尽量真实、不要用买的名单。
- **想改发送时间**：记事本打开「1-启动每日定时发送.bat」，把 `--cron "0 9 * * *"` 的 `9` 改成想要的小时（24 小时制）。
- **发送节奏**：当前一次发 1 封，对腾讯企业邮箱最安全；如需加快改 bat 里 `--concurrency 2`，不建议超过 3。
