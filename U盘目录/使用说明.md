# 客户邮件定时发送器 · 使用说明

双击「**邮件定时发送器.exe**」打开。所有数据都在这个文件夹里：换电脑把整个文件夹拷走即可，无需安装、无需重新配置。

**核心规则**：每个客户只发一次（永久记录，忘关软件也不会重发）；过期的计划自动跳过；全部发完程序自动停止。

---

## 一、快速上手（三步）

1. **选发件邮箱**：已预置 sales@ 和 sue@ 两个账号，下拉框选择即可；不确定账号是否有效就点「**✉ 测试此账号**」给自己邮箱发一封验证；
2. **添加任务**：点「**➕ 添加任务**」——
   - **日期**：鼠标点日历选择；勾选「每天发送」则不用选日期；
   - **时间**：两个小框，时填 `08`、分填 `20` → 即 08:20；
   - 客户名字（自动拼成"Hi 名字,"）、客户邮箱、抄送（可空）、正文、配图（可空）；
   - 保存后任务出现在列表里；
3. **启动**：点「**▶ 启动定时发送**」，窗口保持开着（可最小化）。到点自动发送；**修改任务（加/删）不需要重启**，列表操作即时生效。

## 二、任务列表说明

| 列 | 含义 |
|---|---|
| 日期 | "每天"或具体日期（如 11-20 周五） |
| 时间 | 发送时刻 |
| 状态 | 🟠 待发 / 🟢 已发 / ⚪ 已过期（当天该时刻已过，不会补发） |

- **删除任务**：选中一行点「删除所选」；
- **给发过的客户重发**：删掉文件夹里的 `任务表.state.json`（清空全部发送记录）后重新启动。

## 三、文件夹里有什么

| 文件 | 作用 |
|---|---|
| 邮件定时发送器.exe / mailgrid.exe | 界面 / 发送引擎 |
| 任务.json | 任务清单（界面上添加/删除，自动保存） |
| 发件账号.json | 发件账号簿（下拉切换、＋添加账号） |
| smtp.json | 当前生效的发件配置（界面自动维护，不用动） |
| 任务表.state.json | 已发送台账（自动生成；删除=可重发） |
| base_template.html | 邮件版式（Hi 名字 + 正文 + 名片签名）；改签名文字后**重启软件**生效 |
| poster.jpg / logo.png / badge.gif | 邮件配图：海报（任务配图列引用）、签名 logo、徽章；换图覆盖同名文件 |
| failed.csv | 发送失败的记录（自动生成） |

> ⚠️ 文件名不要改、文件不要删——程序按固定名字找它们；文件**内容**可以改。

## 四、常见问题

- **提示 535 认证失败**：所选邮箱的授权码不对或 IMAP/SMTP 未开启；到邮箱网页版（设置→客户端设置）重新生成**客户端专用密码**，在软件密码框里更新后点「✉ 测试此账号」验证。
- **没收到邮件**：先查垃圾箱/广告邮件；新换的发件账号第一次发信常被归为垃圾，点"不是垃圾邮件"即可。
- **列表显示"已过期"**：该任务的时刻已经过了（比如当天忘了开软件），不会补发；想发就删掉这条重新加一条新时间。
- **客户收到进垃圾箱**：新邮箱前几周每天 20~50 封起步，逐步增加；名单真实。
- **换电脑**：整个文件夹拷走，任务、账号、发送记录全部跟着走。
